概要

Go To Hell は、早稲田大学サークルの日本の友人と一緒に作った最初のHTML・JavaScriptゲームです。

このゲームを作るきっかけは、彼は歴史上の有名人が地獄に行くべきか天国に行くべきかを判断するゲームを作るというアイデアを思いついたことでした。

ゲーム内では、スワイプ操作でキャラクターを空高く投げ上げたり、溶岩に投げ落としたりことで、キャラクターが天国と地獄のどちらに行くべきかを判定できます。

最後に、10人の歴史上の人物を評価した後、ゲームはプレイヤーの性格タイプを教えてくれます。

このゲームは趣味として作ったものですが、同時に、知り合いの人々の性格について理解することもゴールとしていました。

  • 開発言語：HTML / JavaScript / Firebase
  • ツール：Visual Studio Code / Procreate（キャラクターアート）/ Audacity（サウンドエフェクト編集）
  • 使ったAI：Gemini 無料版（デバッグ、困った時コードの書き方を示す）

操作

  • キャラを一番上にドラッグする → 天国行き
  • キャラを一番下にドラッグする → 地獄行き
  • 高く投げ上げる → 天国行き
  • 溶岩に投げ込む → 地獄行き

性格判断

  • 最後に、10人の歴史上の人物を評価した後、ゲームはプレイヤーの性格タイプを教えてくれます。
